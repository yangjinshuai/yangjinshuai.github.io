# 杨金帅的个人主页

这里记录我的个人经历、成长，以及每一次户外徒步。

🌐 主页：[https://yangjinshuai.github.io](https://yangjinshuai.github.io)

## 网站内容

- 个人简介与履历
- 徒步记录：时间、地点、路线、照片和感受
- 累计徒步次数与累计距离

## 更新网站内容

1. 打开个人主页，使用页面中的编辑功能更新资料或徒步记录。
2. 导出更新后的 `content.json`。
3. 用导出的文件替换本仓库根目录中的 `content.json`。
4. 提交并推送到 `main` 分支。

网站内容保存在仓库的文件中。提交更新后，GitHub Pages 会自动重新发布。

## 发布设置

在仓库的 **Settings → Pages** 中，将发布来源设为：

- **Source**：Deploy from a branch
- **Branch**：`main`
- **Folder**：`/(root)`

网站入口文件 `index.html` 位于仓库根目录。
